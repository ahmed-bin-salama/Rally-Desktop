# CSS Stylesheets

This directory contains CSS files for styling the Rally Board Interactive Desktop application.

## Guidelines
- Write clean, modern CSS3 using standard CSS variables (design tokens) for colors, typography, spacing, and z-indices.
- Ensure all styled components match their corresponding IDs defined in `ID_REGISTRY.md`.
- File naming format: `lowercase-kebab-case.css` (e.g., `desktop.css`, `window-manager.css`).
- Do not add CSS frameworks (e.g., Tailwind, Bootstrap) without explicit architectural approval.
