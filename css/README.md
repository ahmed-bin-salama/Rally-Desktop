# CSS Directory

This directory contains stylesheets for the Rally Board Interactive Desktop application.

## Expected Stylesheets (Future Implementation)
- `main.css` or component-specific stylesheets (e.g., `desktop.css`, `topbar.css`, `window.css`, `dock.css`).
- CSS custom properties (design tokens) for colors, typography, spacing, window z-indexes, and animations.

## Rules & Guidelines
- Do NOT hardcode colors or dimensions where CSS variables can be reused.
- Maintain responsive layout logic for desktop and mobile screens.
- Use clean, modular CSS without external heavy frameworks (Tailwind, Bootstrap, etc.) unless explicitly instructed.
