# Assets Directory

This directory stores all static visual media assets used across the Rally Board Interactive Desktop.

## Subdirectories
- `people/`: Member photos and sticker source assets.
- `committees/`: Committee artwork and illustrations.
- `icons/`: UI icons and interface functional graphics.
- `logos/`: Rally branding, logo marks, and header assets.
- `backgrounds/`: Desktop wallpapers and background imagery.
- `textures/`: Subtle paper, noise, or grain texture overlays.

## Naming Conventions
- Always use `lowercase-kebab-case` (e.g., `rally-logo.webp`, `marketing-committee.png`).
- Never use spaces, capital letters, or vague filenames like `IMG_0001.png` or `final2.png`.
- Refer to `ASSET_GUIDELINES.md` in the root directory for detailed asset specs.
