# Static Media Assets

This directory stores all static visual assets used by the Rally Board Interactive Desktop.

## Directory Overview
- `people/`: Transparent PNG/WebP photo stickers of members and board managers.
- `committees/`: Visual artwork and illustrations for each committee.
- `icons/`: UI icons and functional interface graphics.
- `logos/`: Official Rally brand logos and marks.
- `backgrounds/`: Desktop wallpapers and background graphics.
- `textures/`: Subtle grain, paper, or visual overlay textures.

## Naming & Optimization Rules
- File naming convention: `lowercase-kebab-case.ext` (e.g., `rally-logo-white.webp`).
- Preferred formats: `.webp`, `.png` (transparent background where applicable), `.svg` (vector icons).
- All media assets must be optimized for fast web loading.
- Never use random filenames like `IMG_8392.png` or `final2.png`.
