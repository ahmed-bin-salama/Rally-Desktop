# Assets: People

This directory contains individual photos and portrait graphics for members and managers.

## Requirements
- Format: PNG or WebP with transparent backgrounds.
- Source imagery should be clean without permanent artificial shadows or borders baked in (CSS will apply sticker styling/effects dynamically).
- Naming format: `firstname-lastname.webp` or `[id]-name.webp` using `lowercase-kebab-case`.
- Do NOT upload unoptimized raw camera photos.
