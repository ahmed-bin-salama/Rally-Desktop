# Media Asset Guidelines

This document specifies media formats, directory organization, resolution recommendations, and file naming standards for the Rally Board Interactive Desktop.

---

## 1. Asset Directory Organization

- **`assets/people/`**: Member photo stickers, manager cut-outs.
- **`assets/committees/`**: Committee header graphics, banners, illustrations.
- **`assets/icons/`**: Functional interface icons, UI symbols, navigation graphics.
- **`assets/logos/`**: Rally brand logos, logotypes, crest emblems.
- **`assets/backgrounds/`**: Desktop wallpapers and backdrop images.
- **`assets/textures/`**: Subtle grain, paper overlays, and noise textures.

---

## 2. File Format & Optimization Standards

| Asset Category | Preferred Format | Transparency Required | Target Max File Size |
|---|---|---|---|
| **Member Photos** | WebP / PNG | Yes (Transparent Background) | < 250 KB |
| **Committee Art** | WebP / PNG | Optional | < 500 KB |
| **UI Icons** | SVG / WebP | Yes | < 50 KB |
| **Logos** | SVG / WebP | Yes | < 100 KB |
| **Wallpapers** | WebP / JPG | No | < 800 KB |
| **Textures** | WebP / PNG | Optional | < 300 KB |

---

## 3. Naming Convention

All media files must strictly use **`lowercase-kebab-case`**.

### Approved Examples
- `assets/people/ahmed-bin-salama.webp`
- `assets/logos/rally-logo-white.svg`
- `assets/committees/tech-committee-art.webp`
- `assets/backgrounds/desktop-wallpaper-default.webp`

### Prohibited Examples
- `IMG_8392.PNG`
- `final-graphic-v2.png`
- `AhmedBinSalama.webp`
- `test123.png`
