# Asset Guidelines

## File Formats & Paths

- **Backgrounds:** `assets/backgrounds/` (JPEG/WebP)
- **Logos:** `assets/logos/` (SVG/WebP)
- **People / Member Cutouts:** `assets/people/` (PNG/WebP with transparent backgrounds)
- **Committee Graphics:** `assets/committees/` (SVG/PNG/WebP)
- **UI Icons:** `assets/icons/` (SVG)

## Naming Convention

Strict lowercase kebab-case for all assets (e.g., `member-01.webp`, `committee-01.png`, `desktop-background.jpeg`).

## Sticker Asset Rules

1. Transparent backgrounds are required for member cutouts (`.webp` or `.png`).
2. CSS applies white/light border, drop-shadow, and subtle rotation.
3. Assets should be optimized for web performance (< 200 KB per image).
