# Documentation Directory

This directory contains technical architectural specifications, data model diagrams, UI component maps, and deployment guides for the **Rally Board Interactive Desktop** project.

## Documents
- `ARCHITECTURE.md`: High-level tech stack and static client-side architecture.
- `UI_STRUCTURE.md`: Detailed component hierarchy and responsibility breakdown.
- `DATA_MODEL.md`: Entity relationships, bilingual field specifications, and data flow.
- `DEPLOYMENT.md`: Cloudflare Pages deployment flow and hosting configuration.
