# JavaScript Source Code

This directory contains Vanilla JavaScript modules for application logic, state management, window behavior, and rendering.

## Guidelines
- Use standard ES Modules (`import`/`export`).
- Keep code lightweight, modular, and client-side only.
- Separate UI component rendering from data objects in `/data`.
- Always reference elements by stable `RLY-[TYPE][NUMBER]` IDs.
- File naming format: `lowercase-kebab-case.js` (e.g., `window-manager.js`, `language-switch.js`).
- Do not introduce build tools, bundlers, or heavy JavaScript frameworks.
