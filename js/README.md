# JavaScript Directory

This directory contains client-side JavaScript files for the Rally Board Interactive Desktop application.

## Expected Modules (Future Implementation)
- Vanilla JavaScript (ES modules).
- State management / window manager logic.
- Interaction handlers (drag, open/close windows, bilingual language switch, notification panel toggle).
- Dynamic rendering components driven by data from `../data/`.

## Rules & Guidelines
- Do NOT hardcode content or strings inside JavaScript files; read from `data/*.js`.
- Keep modules clean, focused, and well-commented.
- Ensure strict adherence to element IDs defined in `ID_REGISTRY.md`.
